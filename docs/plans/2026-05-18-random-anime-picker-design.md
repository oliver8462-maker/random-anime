# Random Anime Picker - Design Document

## 1. Goal
打造一個選擇障礙之隨機動畫抽取器，讓使用者能夠透過篩選標籤（類型、心情等），一鍵隨機抽出一部巴哈姆特動畫瘋的動畫，並顯示封面、簡介與正版連結。

## 2. Architecture
- **前端框架**：Vite + Vanilla JavaScript
- **樣式 (Styling)**：原生 CSS，採用 Dark Mode 與 Glassmorphism（玻璃透視感）風格，並加入豐富的微動畫與轉場效果，營造「抽卡」的質感。
- **資料來源**：預先撰寫 Node.js 爬蟲腳本（`scraper.js`），去巴哈姆特動畫瘋爬取動畫清單、封面、簡介與連結，並輸出為靜態的 `data.json` 供前端讀取。
- **部署**：完全靜態的網頁，未來可輕易部署。

## 3. UI & Features
- **標籤篩選區 (Filter Section)**：
  - **動畫類型**：對應巴哈姆特的分類（如：熱血、戀愛、科幻等）。
  - **現在心情**：自訂情境標籤（如：想放鬆、想痛哭、需要刺激），透過前端邏輯對應至實際的動畫類型。
- **抽取按鈕 (Randomize Button)**：
  - 位於畫面中央的大型吸睛按鈕，點擊時觸發「正在尋找」的等待動畫。
- **結果展示卡片 (Result Card)**：
  - 包含大面積的高畫質封面、動畫標題、簡介內容。
  - 提供醒目的「前往巴哈觀看」按鈕，直接連結至該部動畫的正版播放頁面。

## 4. Data Flow
1. 開發期：執行 `node scraper.js` -> 抓取巴哈動畫瘋 -> 產生 `public/data.json`
2. 執行期：使用者開啟網頁 -> 前端 fetch `data.json` -> 使用者選擇標籤 -> 點擊抽取 -> 從符合條件的陣列中隨機取出一筆 -> 更新 UI 顯示結果。
